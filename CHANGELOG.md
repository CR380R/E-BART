# Changelog

## Version 1.0

- Released the E-BART model code and data used in the human evaluation.
- Included four crowd tasks with 52 statements and 520 judgments per task.
- Included the task configurations, instructions, response scales and statement order for V1 to V4.
- Provided 2,080 judgments from 514 workers and study labels for 70 statements.
- Expanded the worker data to include available original written justifications and four complementary tables for completion metadata, comments, MTurk assignment information and browser/device categories, retaining each condition's actual source coverage.
- Published pseudonymized worker records without original participant/platform identifiers, private access tokens or raw location data.
- Included reference explanations and E-BART explanations for all 70 statements.
- Provided task descriptions and possible official FEVER IDs for the statements.
- Added the README, citation information, rights information, manifest and SHA256 checksums.
